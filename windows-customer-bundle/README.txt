TBSparcer customer package (no local backend required)

1) Run installer:
   TBSparcer Setup 1.1.0.exe

2) Run config installer script:
   install_client_config.bat

3) Launch TBSparcer from Start Menu.

The app will use remote server API from client-access.json:
- api_base_url: http://64.188.106.221:8000

No local backend is required on the client machine.
